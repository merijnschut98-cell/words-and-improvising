# eng.quality — Quality basics (engineering, track basics, level 1)
Index title: en 'Quality basics' / nl 'Kwaliteit: de basis'. Blurb: en 'Tolerances, capability, control charts and root cause: how engineers talk about good parts.' / nl 'Toleranties, procesgeschiktheid, regelkaarten en oorzaakanalyse: hoe engineers over goede onderdelen praten.'
1. `eng.quality.tolerance` — nominal, tolerance, spec limits; why every dimension has one; what “out of spec” costs.
2. `eng.quality.variation` — common vs special cause variation; mean and standard deviation in plain words.
3. `eng.quality.capability` — Cp and Cpk: what they mean, 1.33 as a common target, centred vs not centred.
4. `eng.quality.spc` — control charts (X-bar/R), control limits ≠ spec limits, the rules that signal a problem.
5. `eng.quality.fmea` — FMEA: severity, occurrence, detection, RPN/action priority; using it before a launch.
6. `eng.quality.controlplan` — control plan and measurement (gauges, MSA/gauge R&R in one idea), PPAP in one paragraph.

Recalculations and sources:
- Tolerance: Ø12 +0.018/0 = H7 for 10–18 mm (ISO 286). ISO 2768-m: ±0.2 mm for over 6 up to 30 mm. Hair ≈ 70 µm, so ±10 µm ≈ 1/7 hair. Example: 15 / 500 = 3%; 15 × 4.50 = 67.50; 500 × 0.80 = 400; 400 + 250 + 67.50 = 717.50 ≈ 10.6 × 67.50 (“ten times”). 1-10-100 rule as a rule of thumb.
- Variation: 68 / 95 / 99.7% rule. Tampering: Deming’s funnel rule 2 doubles the variance, so σ × √2 ≈ +41% (“about 40%”). Deming: 94% of problems belong to the system (*Out of the Crisis*, 1986) → “over 90%”. Example 20.003 ± 0.024 = 19.979 … 20.027.
- Capability: 0.10 / 0.075 = 1.333; shift 0.025 → 0.025 / 0.0375 = 0.667. Centred Cpk 1.33 = ±4σ → 2 × 31.7 = 63 ppm; 1.67 = ±5σ → 0.57 ppm; 1.0 = ±3σ → 2,700 ppm. Ppk ≥ 1.67 for preliminary studies and 125 readings (25 subgroups × 5) per AIAG PPAP / SPC manuals. Example: 0.040 / 0.024 = 1.67; 0.014 / 0.012 = 1.17; 0.020 / 0.012 = 1.67.
- SPC: Shewhart, Bell Labs, 1924. A2 (n = 5) = 0.577; 0.577 × 0.020 = 0.01154 → 19.9885 … 20.0115; recall UCL 50 + 0.0577 = 50.0577. Run rules: AIAG 7, Western Electric 8, Nelson 9 on one side; Nelson trend rule 6 rising; WE 2 of 3 beyond 2σ.
- FMEA: AIAG-VDA FMEA Handbook, 1st ed. June 2019 (Action Priority replaces RPN). Example 8 × 5 × 7 = 280 → 8 × 5 × 2 = 80; recall 7 × 4 × 5 = 140.
- Control plan: AIAG MSA 4th ed. %GRR under 10 / 10–30 / over 30%. Example 0.04 / 10 = 0.004; 10 × 3 × 3 = 90; 6 × 0.001 = 0.006; 0.006 / 0.04 = 15%. PPAP level 3 = PSW + samples + full supporting data (default).

Facts fixed: the “said” line in the capability lesson read “Cp is 1.7 but Cpk is 1.1” while the example gives 1.67 and 1.17 (1.17 rounds to 1.2, not 1.1); it now says 1.67 and 1.17. Facts, recalculations and sources:
- gauges: rule of ten (AIAG MSA). Steel α ≈ 11.5 µm/(m·K): 0.1 m × 10 K → 0.0115 mm; example 0.030 m × 8 K × 0.0115 = 0.0028 mm; recall 0.2 × 5 × 0.0115 = 0.0115 mm. Reference temperature 20 °C (ISO 1). ISO 9001:2015 7.1.5.2: when equipment is found unfit, judge whether previous results are still valid.
- gdt: ASME Y14.5-2018; ISO 1101 + ISO 8015 (independency principle) vs ASME Rule #1 (envelope). Square ±0.1 → diagonal 0.283 → circle Ø0.28; area π·0.1414² / 0.04 = 1.57 (“57% more”). Example 2·√(0.09² + 0.12²) = 0.30; bonus 8.15 − 8.0 = 0.15 → Ø0.35. Recall 2·√(0.03² + 0.04²) = 0.10; 0.1 + (12.2 − 12.0) = 0.3.
- stackup: worst case vs RSS; √(4·0.01) = 0.2; √(10·0.01) = 0.316. Bender factor 1.5 (A. Bender, SAE paper, 1960s; empirical, hedged) — Scholz, Boeing ISSTECH-95-030; wevolver “worst case vs RSS”. Example √(0.04 + 0.0075) = 0.218; × 1.5 = 0.327. Recall √0.0169 = 0.13; 0.03 + 0.04 + 0.12 = 0.19.
- capstudy: Bosch booklet 9 via supplier sampling form (SupplyOn): Cm/Cmk ≥ 1.67, n ≥ 50 consecutive parts; Cp/Cpk ≥ 1.33. Cpk confidence bound (Bissell approximation, cf. NIST e-Handbook 6.1.6): 1.33, n = 30 → 1.33 − 1.96·√(1/270 + 1.769/58) = 0.97 (“about 1.0”); n = 125 → 1.16. Percentile method 0.135 % / 99.865 % (ISO 22514-2). Example (0.050 − 0.020) / 0.018 = 1.67; recall 0.6 / 0.36 = 1.67. The “about 1.3” in the faded reveal is labelled a supposition.
- sigma: Motorola, Bill Smith (1986), 1.5σ shift → 3.4 DPMO; centred 6σ ≈ 0.002 ppm; table 66,807 / 6,210 / 233 / 3.4 = one-sided tails at 1.5 / 2.5 / 3.5 / 4.5σ. Wheeler, *The Six Sigma Zone* (2003) on the shift. Teach 35 / 500,000 × 10⁶ = 70; RTY 0.95·0.98·0.97 = 0.903; example 0.96·0.92·0.99·0.97 = 0.848. Recall 40 / 500,000 × 10⁶ = 80; 0.9·0.95·0.98 = 0.8379.
- datatools: Ishikawa’s seven basic tools; Pareto principle named by Juran (rule of thumb, hedged). Run chart rules per IHI / Perla, Provost & Murray (BMJ Qual Saf 2011): shift ≥ 6 on one side of the median, trend ≥ 5; other sources differ (hedged). Example 7 + 8 + 8 + 18 + 21 = 62; 62 / 120 = 52%; 87 / 120 = 73%. Teach 27·1 % + 3·20 % = 2.9 % (“about 3%”).
- chartchoice: I-MR limits x̄ ± 2.66·MR̄ (3 / d2, d2 = 1.128); p chart p̄ ± 3√(p̄(1 − p̄)/n); c chart c̄ ± 3√c̄ (NIST e-Handbook 6.3; Montgomery). Example √(0.03·0.97/400) = 0.00853 → 5.56 % / 0.44 %; 26/400 = 6.5 %, 1/400 = 0.25 %. Recall 8.50 + 2.66·0.12 = 8.819; √(0.000098) = 0.0099 → 4.97 %.
- spcpractice: in-control ARL 1/0.0027 ≈ 370; with the four Western Electric rules ≈ 91.75 (Champ & Woodall, Technometrics 29, 1987; quoted in NIST e-Handbook 6.3.2). 92 / 8 per day ≈ 11.5 days. A2 (n = 4) = 0.729; 0.729 × 0.060 = 0.044. Pre-control: Satterthwaite at Rath & Strong, 1954, promoted by Shainin; critique Ledolter & Swersey (1997). Recall 370 / 10 = 37 days.
- nonconform: ISO 9001:2015 clause 8.7 (control of nonconforming outputs). ASQ Cost of Quality page: 15–20 % of sales, up to 40 % (hedged as a rough estimate). Example 4 h × 30 = 120; 120 × 30 s = 1 h. Recall 3.5 h × 40 = 140.
- eightd: Ford, Team Oriented Problem Solving (1987); D0 added later (Global 8D, 1990s). 5 whys (Toyota), Ishikawa / 6M. Containment within 24 h is a common customer rule, varies (hedged). Recall 45 / 150,000 × 10⁶ = 300 ppm.
